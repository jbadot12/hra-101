# HRA 101 Interactive

## Status

- Stage: Revised interactive prototype
- Created: September 9, 2026
- Audience: New Unlock team members and live prospect conversations
- Format: Single-page HTML with local visual assets and no framework dependencies

## Narrative direction

The experience explains HRAs through the consumer journey. It begins with the gap between initial interest and readiness to schedule, then shows how acquisition channels, the clinical framework, personalized next steps, follow-up, and downstream reporting work together.
